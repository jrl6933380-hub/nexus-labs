# Nexus Intelligence — Competitor Page Changes

Inspect exact public HTTPS page URLs and get structured, source-backed observations. Compare to previous successful results to see added and removed passages. No Nexus account, Nexus server access or Redis credentials are required.

## Input

```json
{
  "urls": ["https://www.iana.org/help/example-domains"],
  "maxPages": 10,
  "includeText": true,
  "previousResults": []
}
```

The first successful capture is a `baseline`. For a later run, pass the earlier `captured` rows as `previousResults`. Failed rows must be excluded. Include source text in the earlier output if you need comparisons. Baselines are caller-supplied; the Actor does not silently read or share any other run's stored data. Redirects preserve the original `requestedUrl` for baseline matching.

## Output contract

Every selected URL produces either a successful captured row or a failed inspection row unless the run stops for budget or a platform/storage failure.

- `schemaVersion`: currently 1.
- `requestedUrl`, `url`: original and resolved source URLs.
- `status`: `captured` or `failed`.
- `capturedAt`, `checkedAt`, `previousCapturedAt`: observation times.
- `comparison`: `baseline`, `changed`, `unchanged` or `unavailable`.
- `title`, optional `text`, `contentHash`: source evidence.
- `added`, `removed`: up to eight excerpts each, maximum 600 characters each.
- `observedAmounts`: up to 30 literal amount strings found in the text. These are not verified plan prices or inferred prices.
- `screenshotUrl`: null; no screenshots are generated by this version.
- `error`: a coverage gap when inspection fails.

`SUMMARY` in the run's key-value store records selected, attempted, successful and failed counts and whether work stopped at the result budget. Dataset rows can be exported through Apify's normal dataset interface/API; a custom dashboard is not needed.

## Billing preparation

The proposed pay-per-event identifier is `page-result`. Each successful page capture is one result, including baseline, changed and unchanged captures. Failed inspections are emitted without this event. Duplicate URLs in a run are captured once. No retry loop is enabled.

**The code does not set a price or activate monetization.** An owner must configure the event and price in the Apify Console, review the platform's current commission/usage rules, and test the caller's maximum-charge behavior before publication. If the event is not configured, the SDK treats it as unpriced; the code alone cannot earn revenue. The runtime checks the remaining result budget before each network operation. Ordinary platform usage costs can still apply even when a capture fails or the event is unpriced.

There is no promotional Nexus funnel in this Actor listing. Distribution of the separate Nexus interface does not require an Actor user to sign up elsewhere.

## Limits

Public HTTPS/443 only; no login cookies, proxy credentials, browser JavaScript, screenshots, ads, search discovery, or AI-generated interpretations. DNS and redirects are validated and the checked IP is pinned. A page has a 12-second network budget and 1 MB download ceiling; extracted text is limited to 24,000 characters. JavaScript-only and access-challenged pages can fail. The HTML extractor is heuristic; benign changes can appear in diffs. No conversion, revenue or competitor-performance claims are generated.

## Build and test

The repository root is the build context. `.actor/actor.json` points to this package's Dockerfile and schemas.

```sh
node --test test/intelligence.test.mjs test/intelligence-batch.test.mjs
docker build -f actors/intelligence/Dockerfile -t nexus-intelligence .
docker run --rm -v "$PWD/storage:/usr/src/app/storage" nexus-intelligence
```

For a local container run, place input at `storage/key_value_stores/default/INPUT.json` first. Alternatively connect the Git repository root in Apify's source configuration. Docker copies the same `lib/intelligenceCapture.js` engine used by Nexus, not a fork. Only the Actor package installs Apify SDK 3.7.0; Nexus's root dependency tree is unchanged.

Publication, account setup, pricing, real Apify billing tests, and marketplace demand validation are separate launch steps. This package has not been listed or monetized by committing its source.
