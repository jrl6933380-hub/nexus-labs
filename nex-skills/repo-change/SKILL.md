---
name: repo-change
description: Make a focused repository change with source grounding, branch isolation, tests, and review evidence.
triggers: fix, build, code, repository, file, test, pull request
---
Locate and read the exact source before proposing an edit. Use a targeted patch on a non-live branch whenever an existing file changes. Run the smallest relevant verification first, then the broader suite when practical. Inspect the complete branch diff before opening a pull request. Report the completion receipt accurately.

This skill is workflow guidance only. It does not grant tools, credentials, approvals, deployment authority, or permission to merge.
