description: Evaluate a consequential architecture decision using alternatives, constraints, failure modes, and evidence.
triggers: architecture, design, migration, security, scalability, database
---
State the decision and constraints. Compare at least two viable approaches, including operational cost and failure recovery. Separate verified current-system facts from assumptions. For a proposed code change, identify affected boundaries and the tests that would falsify the recommendation.

This skill supplies reasoning structure only. Runtime policy and backend approval gates remain authoritative.
